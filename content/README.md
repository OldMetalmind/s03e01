# Public content boundary

`requirements.json` and `requirements.md` contain only sanitized, non-secret content approved for public scaffolding.

Do not add:

- original memo, screenshot, recording, PDF, or whiteboard files;
- private review derivatives or transcripts;
- upload tokens, credentials, cookies, or tokenized URLs;
- a requirement without a source ID and locator;
- an unresolved product conflict as if it were settled.

The `state` field must remain `awaiting-course-acceptance` until MEGA.dev accepts the consolidated requirements list.
